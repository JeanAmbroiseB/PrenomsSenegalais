Connexion

Relisez chaque proposition, corrigez-la si besoin, puis publiez-la : elle apparaît aussitôt sur le site avec le nom de son auteur. Une signification déjà présente sur le site reste affichée en premier ; la nouvelle s'ajoute dans « Autres éclairages ». Une nouvelle écriture devient une « autre graphie ».

Affiches et bâches à livrer bêta

Collez le message de commande reçu sur WhatsApp (il contient un code « PS2-… »). Vérifiez d'abord la réception du paiement, corrigez le texte si besoin, puis téléchargez le fichier et renvoyez-le sur WhatsApp. Les formats à imprimer sortent en PDF à la taille réelle ; les formats pour écrans en PNG.
